# Job Hunt Command Center

A local, no-backend dashboard for a 30-day AI/GenAI/Python backend job search.

## Run
Open `index.html` in Chrome/Edge.

Data is stored in the browser's localStorage, so jobs and checklist progress stay on the same browser/device.

## Included
- Dashboard metrics
- Job tracker with stages
- Search/filter
- Add/delete jobs
- Recruiter/referral tracker
- Interview preparation checklist
- 30-day sprint view
- Settings for target roles/salary/location

## Next upgrade
This first version is intentionally local and simple. A later version can add FastAPI + PostgreSQL, job-feed ingestion, duplicate detection, email/calendar integration, authentication, and server-side notifications.
